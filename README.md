Репозиторій для тренування роботи з гілками та комітами:

У процесі виконання завдання я вивчила основні команди Git: ініціалізацію репозиторію, додавання файлів, створення комітів, роботу з гілками та публікацію змін на GitHub. Під час виконання траплялися деякі помилки в командах (наприклад, неправильний синтаксис або дублювання remote), які я вчасно помітила і виправила. Це було частиною вивчення, що допомогло краще зрозуміти принципи роботи з Git. В підсумку всі необхідні зміни закомічені та відправлені у відповідні гілки, репозиторій знаходиться у робочому стані.
